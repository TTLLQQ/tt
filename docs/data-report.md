# 数据与持久化说明

当前实现按老师所列建立十张 SQLAlchemy 业务表，SQLite 开启外键约束，并由 Alembic `0001_initial` 建立 schema。迁移表 `alembic_version` 属于 Alembic 元数据，不是业务表。

数据类型：账号（用户名、bcrypt 密码摘要、管理员标记）、好友与房间关系、消息（类型/风险标记/时间）、模型配置密文、工具 schema 与惰性源码元数据、员工绑定及调用审计（JSON 入参、结果、状态、毫秒耗时）。

没有真实采集样本或数据集质量报告可统计；聊天与模型数据为空时分析图表显示空集合。生产使用前需确定保留期限、授权依据、访问控制、备份恢复和删除请求处理。
